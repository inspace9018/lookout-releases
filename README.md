# Lookout

데드락(Deadlock) 화면 오버레이입니다. 게임 화면을 읽어 라인전 상대, 적 궁극기, 정글·오브젝트 타이머,
상점 대응 아이템, Tab 화면 팀 정보를 보여 줍니다. 한국어 클라이언트 기준입니다.

이 저장소에는 설치 파일만 올라옵니다.

## 받기

**[최신 버전 받기 (Lookout-Setup.exe)](https://github.com/inspace9018/lookout-releases/releases/latest/download/Lookout-Setup.exe)**

이전 버전과 변경 내용은 [Releases](https://github.com/inspace9018/lookout-releases/releases)에 있습니다.

## 설치

1. `Lookout-Setup.exe`를 실행합니다.
2. 'Windows의 PC 보호'가 뜨면 **추가 정보 → 실행**을 누릅니다. 아직 코드 서명이 없는 빌드라서 뜹니다.
3. Deadlock은 창 모드나 테두리 없는 창 모드로 실행합니다.

0.1.3부터는 앱이 새 버전을 알아서 받고, 끌 때 설치합니다.

## 피드백

버그나 제안은 [이슈로 남겨 주세요](https://github.com/inspace9018/lookout-releases/issues/new/choose). 앱의 트레이 메뉴 '피드백 보내기'로도 열 수 있습니다.
게임 화면과 오버레이가 같이 보이는 스크린샷이 있으면 가장 빨리 고칩니다.

## 알아 둘 것

- 화면만 읽습니다. 게임 메모리를 읽거나 게임 파일을 바꾸지 않습니다.
- 화면 인식은 PC 안에서만 합니다. 게임 화면을 밖으로 보내지 않습니다.
- 영웅 통계는 deadlock-api.com에서 받아 옵니다.
- Valve와 관계없는 팬 제작 도구입니다. Deadlock과 그 이미지의 권리는 Valve에 있습니다.
- 각 릴리스 설명에 설치 파일의 SHA256이 있습니다.
